# ბილიკი · Грузинский A1

Интерактивный курс грузинского языка для русскоязычных, живущих в Грузии. Уровень A1, бытовые темы, порядок тем как в учебнике «Билики».

- Алфавит группами + чтение слов из знакомых букв
- 11 уроков: слова, фразы, диалоги, грамматика, практика, миссии в реальной жизни
- Интервальные повторения (SM-2), тренажёр чисел и цен, разговорник
- Читалка: свой текст → клик по слову → перевод, разбор формы, склонение/спряжение, примеры; онлайн-перевод и ИИ-разбор (Claude, свой ключ API)
- Экранная грузинская клавиатура, транскрипция кириллицей
- Озвучка через голоса браузера (лучше всего в Microsoft Edge)

Прогресс хранится в браузере (localStorage). Без сборки — просто откройте `index.html`.
